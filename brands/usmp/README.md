# Brand académico USMP

Overlay tipográfico y funcional para presentaciones académicas de BibliotecaWeb.

Incluye la denominación de la Universidad de San Martín de Porres, Facultad de Ingeniería y Arquitectura, escuela, curso y autor opcional. La información variable llega desde `brandData`.

Este brand no copia ni pretende sustituir el logotipo oficial o un manual institucional. Si posteriormente se incorporan recursos gráficos oficiales, deben provenir de archivos autorizados, mantenerse localmente y documentar su procedencia.

Referencia institucional consultada: <https://usmp.edu.pe/universidad-de-san-martin-de-porres-presenta-su-nueva-identidad-corporativa/>.
